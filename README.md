# Performance Optimizer

Performance Optimizer is a Fabric mod for Minecraft 1.21.1 designed to enhance performance in heavy modpacks by implementing dynamic entity and block entity throttling. This mod focuses on reducing CPU strain by throttling AI ticks for distant mobs and skipping ticking for block entities outside the player's render distance. It uses FastUtil for efficient memory management and is compatible with other optimization mods like Sodium, Lithium, and ModernFix.

## Install

1. Install Fabric Loader for Minecraft 1.21.1.
2. Download the PerformanceOptimizer.jar file from the GitHub repository.
3. Place the PerformanceOptimizer.jar file in your mods folder.
4. Launch Minecraft with Fabric.

## Use

1. Launch Minecraft with the mod installed.
2. Access the mod's configuration menu through the in-game mod menu.
3. Adjust the settings as needed:
   - Enable or disable entity optimization.
   - Enable or disable block entity optimization.
   - Set the tick intervals for entities and block entities.
4. Save your configuration and enjoy the optimized performance.
